# Security policy

LLM Sidebar stores API keys locally in the browser and sends requests only to the provider the
user configured. If you find a vulnerability – for example a way for a web page to read API keys,
settings or chats, to trigger requests without user action, or to inject script into extension
pages – please **do not open a public issue**.

Instead, report it privately via GitHub's
[security advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" on the repository's Security tab). Please include steps to reproduce
and the affected browser and version. You will get an answer as soon as possible.

Only the latest release is supported with security fixes.
